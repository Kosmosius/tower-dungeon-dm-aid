THE CROWN — DM AID · GEWINN-only public package · 19 October 2026

FASTEST START
Open https://kosmosius.github.io/tower-dungeon-dm-aid/?mode=dm in a browser.
The complete DM guide is included; there is no content-pack import on a fresh browser.
Choose Open DM aid, then begin a campaign. Reading a key does not move the party.

INSTALL ON A PHONE OR DESKTOP
iPhone: open the URL in Safari, use Share > Add to Home Screen, then Add.
Android: open the URL in Chrome, use the menu's Install app or Add to Home screen.
Desktop Chrome: open the URL and use the install icon or menu's Install page as app.
Wait for the guide to load once while online before relying on offline use.

YOUR DATA
Campaigns stay in this browser on this device; they do not sync through GitHub.
Use Campaigns and backups > Export private backup before changing devices or clearing browser data.
Restore that file through Import or restore on the other device. Keep your backup private.

ABOUT THIS ZIP
This ZIP is the exact static site output. It can be hosted unchanged on any HTTPS
static host. Opening index.html directly from a file:// URL is not supported:
browser storage, content fetch, service workers and phone installation need a
proper web origin. The GitHub Pages URL above is the ready-to-use host.

SCOPE
This is a DM reading and campaign aid with all locality and Way keys. Solo
automation is incomplete and is disabled for this public bundle. The included
GEWINN-only content projection excludes alternate B/X–OSE rules text. Source
credits and software notices are in credits.html and THIRD_PARTY_NOTICES.txt.
